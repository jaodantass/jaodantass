## Main projects

### SGSE — School Management System

A web-based system developed to support school administration processes for multiple schools.

- Built REST APIs using **TypeScript, Node.js, Express and Prisma**
- Worked with **SQL databases**, business rules and data validation
- Contributed to backend logic, database integration and system workflows
- Used **GitHub** and agile practices during the development process

### USD/BRL Exchange Rate Forecasting with Machine Learning

Final-year Computer Science project focused on forecasting the USD/BRL exchange rate using data science and machine learning techniques.

- Built a Python pipeline for data collection, preprocessing and model evaluation
- Worked with **Pandas, scikit-learn, XGBoost, TensorFlow/Keras and MySQL**
- Used time-series features, economic indicators and model comparison
- Evaluated models using metrics such as **MAE, RMSE and directional accuracy**
- Explored model interpretability using **SHAP**
